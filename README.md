
# Text Summarization Tool

## Internship
EliteTech AI Internship - Task 1

## Description
This Python project creates a concise summary from
a longer article by scoring sentences according to
the frequency of meaningful words.

## Features
- Accepts user-provided text
- Selects important sentences
- Lets users choose the summary length
- Displays original and summary word counts
- Handles empty input and invalid sentence counts

## Technologies Used
- Python 3
- Regular expressions
- Basic Natural Language Processing concepts

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python summarizer.py
5. Enter an article and choose the number of sentences.

## Method
The program counts meaningful word frequencies,
scores sentences, selects the highest-scoring ones,
and restores their original order.

## Limitations
This is a basic extractive summarizer. It selects
sentences from the original article rather than
generating new sentences. Its results may not always
capture the main idea perfectly.
